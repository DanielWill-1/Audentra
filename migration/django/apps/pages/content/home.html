Architecture & Privacy

Designed with sensitive data in mind.

Voice and conversational form filling use cloud AI in this build after a one-time opt-in. See the Privacy Notice for data sent and saved.

Deployment and providers

The application can run on operator-managed infrastructure, but AI requests still go to the configured provider.

Provider configuration applies

Saved forms and recordings

After you opt in, recordings are sent to the configured speech provider and are not saved as completed-form records. Uploads may be temporarily buffered.

See retention details

Cloud AI processing

After you opt in, the VoiceForm server sends audio and form-filling text to Groq over its HTTPS API. Per-user provider selection and BYOK are not available in this release.

Provider terms apply

Data retention

Saved forms remain in the configured database until deleted. Groq retention controls and hosting backups are managed separately.

See the Privacy Notice

Account and form access

The Django app checks signed-in users and applies owner-scoped policies to saved forms and private template files.

Current Django app

Operational logs

Application logs use fixed event labels and omit request content. Hosting and proxy logs depend on the deployment.
