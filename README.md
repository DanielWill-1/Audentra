# Audentra

The active application is the Django project in [`migration/django`](migration/django/). Its local setup and run instructions are in the [Django README](migration/django/README.md) and the [P10 local runbook](docs/deployment/P10_LOCAL_RUNBOOK.md).

The retired React/Vite and Express application, its build configuration, and its former CI workflow are preserved under [`legacy/`](legacy/). They are not part of the active build or runtime. Historical design captures, parity evidence, Supabase migrations, and migration records remain in their existing documentation and data folders.

P11 archives the legacy application locally. It does not deploy the Django app or modify hosted services.
