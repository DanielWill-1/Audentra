# Archived application code

This folder preserves the former React/Vite client, Express services, Node package and build configuration, static design drafts, and legacy CI workflow. The active product runtime is now Django under `migration/django/`; do not include this folder in Django runtime, build, or deployment inputs.

The former root structure is retained here so its source and history remain inspectable. `README.original.md` is the pre-P11 repository README. Historical screenshots and parity reports remain in their existing evidence folders.
