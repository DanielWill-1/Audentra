02 / Semantic Parsing & Entity Classification

Understanding relational context beyond raw string tokens.

Standard speech recognition outputs unannotated strings with punctuation guesswork. Audentra parses acoustic tokens into an annotated semantic dependency tree, actively isolating critical modifiers, clinical negation flags, and numerical bounds.

  • check_circle Negation Scope Disambiguation: Identifies syntactic inversions such as “denies fever or chills”, annotating target symptoms as explicit false boolean states.
  • check_circle Temporal Normalization: Resolves phrases like “three days ago at dusk” directly into strict ISO-8601 UTC timestamps.
  • check_circle Domain Lexicon Cross-Referencing: Maps spoken jargon to controlled vocabularies (e.g. SNOMED-CT, ICD-10, or custom proprietary taxonomies).

03 / Declarative JSON Schema Mapping

Enforce arbitrary schema contracts with zero post-hoc hallucinations.

Define target structures via standard JSON Schema, TypeScript definitions, or Pydantic models. Audentra uses grammar-constrained sampling at generation time, physically precluding any token emission that violates your structural validation rules.

code schema_contract.json
JSON Schema Draft-07 
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "type": "object",
  "properties": {
    "patient_id": { "type": "string", "pattern": "^PT-[0-9]{5}$" },
    "triage_urgency": {
      "type": "string",
      "enum": ["routine", "urgent", "stat"]
    },
    "vitals": {
      "type": "object",
      "properties": {
        "systolic": { "type": "integer", "minimum": 50, "maximum": 240 },
        "diastolic": { "type": "integer", "minimum": 30, "maximum": 150 }
      },
      "required": ["systolic", "diastolic"]
    }
  },
  "required": ["patient_id", "triage_urgency", "vitals"]
}

04 / Deterministic Validation & Confidence Scoring

Operator-in-the-loop sign-off with granular token confidence.

In safety-critical workflows, automated parsing requires unambiguous oversight. Audentra computes acoustic and semantic confidence scores per individual field, presenting clean visual cues and tactile inline editing buffers prior to dispatch.

Field-Level Log-Probability

Each generated attribute calculates log-likelihood against the acoustic frame index, pinpointing any ambiguous syllables for swift review.

Immutability Lock

Once approved by an operator, the resulting payload is cryptographically hashed with timestamp and operator metadata.

06 / Autonomous Deployment & Air-Gap Readiness

Run entirely on-premise without an internet connection.

Enterprise compliance often prohibits cloud audio transmission. Audentra runs self-contained as a unified binary, single Docker container, or Kubernetes StatefulSet backed by quantized whisper.cpp and llama.cpp local execution backends.

Zero outbound phone-home network calls
CPU-optimized AVX-512 & ARM NEON acceleration
Native NVIDIA CUDA & Apple Metal kernel support
DEPLOYMENT_RECIPES ARCH: x86_64 / arm64
1. Single Docker Command (Local Offline Server)
docker run -d -p 8080:8080 \
  -v $(pwd)/models:/app/models \
  -e AUDENTRA_AIRGAP=true \
  ghcr.io/audentra/audentra-core:v0.8.2
2. Kubernetes Helm Chart Deploy
helm repo add audentra https://charts.audentra.org
helm install audentra audentra/audentra --set resources.gpu.enabled=true
3. Native Standalone CLI Ingestion
audentra ingest --device default --schema ./triage.json --stdout
