## Shared acceptance rules

- Capture source and Django with equivalent sanitized synthetic state and clock. Enforce all source sections/order, copy, field identities/types/labels, controls and fixed local destinations through named mappings; reject unregistered differences and deliberate source/target removals at the real route comparison boundary.
- Review layout, fonts, spacing, icons, wrapping, drawers/dialogs, focus and overflow at both viewports. Do not invent an image-difference score.
- Treat anonymous application redirects and the intentional `/reset-password` 404 as explicit route behavior. The optional valid recovery-token state requires a future P4-approved test boundary and remains `NOT RUN`.
- Keep browser fixtures separate from hosted persistence/RLS/Storage proof. P9 schema inspection is read-only. Physical device and live provider rows remain `NOT RUN` without the required device/provider scope.
- Store each P9 result and command ledger under [`evidence/p9/p9-initial-readonly-20261013/`](evidence/p9/p9-initial-readonly-20261013/). Current retained P7 evidence is summarized in [P7 SR closeout](../pages/P7_SR_CLOSEOUT_2026-10-13.md).
